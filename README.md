### Hamiltonian Path Problem
Graph G, directed or undirected, verteces s and t, starting and ending
vertex of hamiltionian path. If there exists path starting in s and ending in t such that it visits each vertex exactly once, then this path is called Hamiltonian path and we have solution to Hamiltonian Path Problem.
